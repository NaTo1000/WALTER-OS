# Quick Start Guide - WALTER-OS Spectacular Flipper

## Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Game
```bash
python flipper.py
```

### Step 3: Play!
- Use **LEFT SHIFT** or **A** for left flipper
- Use **RIGHT SHIFT** or **D** for right flipper
- Build combos for massive score multipliers!

## Pro Tips

### Maximize Your Score
1. **Keep the Ball Moving** - Don't let it sit idle
2. **Hit Multiple Targets Quickly** - Build those combos!
3. **Use Both Flippers** - Strategic positioning is key
4. **Aim for Bumpers** - They give the most points
5. **Watch the Multiplier** - It resets after 3 seconds of no hits

### Combo System
- 5+ consecutive hits = 2x multiplier 🔥
- 10+ consecutive hits = 3x multiplier 🔥🔥
- 20+ consecutive hits = 5x multiplier 🔥🔥🔥

### Visual Cues
- **Yellow/Orange Flippers** - Press to activate
- **Blue Bumpers** - Hit for 100-200 points
- **Cyan Targets** - Hit for 50-100 points
- **Particle Explosions** - You just scored!
- **Combo Counter** - Appears after 5+ hits

## Troubleshooting

**Game won't start?**
- Make sure Python 3.8+ is installed
- Install pygame: `pip install pygame`

**No display?**
- This requires a graphical environment
- Use `test_flipper.py` to verify components without display

**Controls not working?**
- Make sure the game window has focus
- Try using both control options (Shift keys or A/D)
