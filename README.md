## 🎯 How to Play

### Installation

1. **Install Python** (3.8 or higher)
2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

### Running the Game

```bash
python flipper.py
```

Or make it executable:
```bash
chmod +x flipper.py
./flipper.py
```

### Controls

| Control | Action |
|---------|--------|
| **LEFT SHIFT** or **A** | Activate left flipper |
| **RIGHT SHIFT** or **D** | Activate right flipper |
| **SPACE** | Restart game (when game over) |
| **ESC** | Quit game |

### Scoring Strategy

1. **Hit bumpers** for big points (100-200 per hit)
2. **Target the targets** for bonus points (50-100 per hit)
3. **Build combos** by hitting multiple objects quickly
4. **Maintain momentum** - Don't let the ball sit idle
5. **Use both flippers** strategically to control the ball

### Multiplier System

- **5+ hits** → 2x multiplier
- **10+ hits** → 3x multiplier  
- **20+ hits** → 5x multiplier (MAX!)

Combos reset after 3 seconds of inactivity, so keep the action going!
