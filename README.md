# WALTER-OS

🎮 **WALTER-OS Game Center** - A collection of fun games where you can challenge Wally, the AI opponent!

## About

WALTER-OS is a web-based gaming platform featuring multiple games where you can test your skills against Wally, an intelligent AI opponent. Each game offers a unique challenge and fun gameplay experience.

## Games Available

1. **Tic-Tac-Toe** ❌⭕
   - Classic 3x3 grid strategy game
   - Wally uses smart AI to challenge you
   
2. **Rock Paper Scissors** ✊✋✌️
   - Quick-paced game of chance and strategy
   - Keep score across multiple rounds
   
3. **Number Guessing** 🔢
   - Guess Wally's secret number between 1-100
   - Get hints along the way (too high/too low)
   
4. **Coin Flip** 🪙
   - Simple yet exciting heads or tails game
   - Track your wins against Wally

## How to Play

1. Open `index.html` in your web browser
2. Choose a game from the main menu
3. Follow the on-screen instructions to play
4. Have fun challenging Wally!

## Technologies Used

- HTML5
- CSS3 (with modern animations and gradients)
- Vanilla JavaScript (no frameworks required)

## Features

- 🎨 Modern, responsive design
- 🤖 Smart AI opponent (Wally)
- 📊 Score tracking for competitive games
- 🎯 Clean, intuitive interface
- 📱 Mobile-friendly

## Installation

No installation required! Simply:
1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start playing!
